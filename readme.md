# This is a simple Dashboard
Made by Dilip Acharya while learning PHP and laravel 
and this dashboard has many features ranging from meeting announcement
to a dashboard where you can view all of the progress made by the club
in the form of Posts and also you can view the members of the club and their details in the members section
and an admin pannel for the leaders.

# Features
- Dashboard Posting for Leaders
- Dashboard Post viewing for members
- Meeting Announcement for Leaders
- Meeting Announcement viewing for members
- Members details everyone
- Admin Pannel for leaders to modify the details of the members

# Run Locally
- Clone the project
- Rename the example.env file to .env
- Start your apache and mysql server and create a database named "justaSimpleDatabase"

Then Simply run it like you would run every laravel program.
